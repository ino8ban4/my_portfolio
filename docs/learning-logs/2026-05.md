# 学習ログ 2026-05

## Issue #19: TypeScript基礎学習 - 型システム入門

### 学習内容

#### 基本的な型
- プリミティブ型（string, number, boolean）、配列、オブジェクトへの型アノテーション
- 型推論：変数は省略可能、関数の引数は必須
- const/let の使い分け：再代入しないならconst、するならlet
- any vs unknown：anyは型チェックを放棄、unknownは型ガードが必要

#### type / interface
- type：=を使う、Union型が使える、同名再定義不可
- interface：同名でマージ追加可能、ライブラリの型拡張に向いている
- 基本はtypeを使う、ライブラリ拡張が必要なときはinterface

#### Union型 / Optional
- Union型：string | number のように「AまたはB」を表現
- Optional（?）：プロパティを省略可能にする
- 文字列リテラルのUnion："admin" | "guest" で取りうる値を制限できる
- Union型は型ガードで絞り込んでから使う

#### Generics
- 型を引数として受け取る仕組み
- anyとの違い：返り値の型が保証される、混在した配列を弾ける
- extends で制約をつけられる：T extends { id: number }
- 典型的なユースケース：APIレスポンスの共通ラッパー型

#### FastifyでTypeScriptの型を使う
- fastify.get<{ Params, Querystring, Body, Reply }> でルートに型をつける
- URLパラメータは常にstring → 必要に応じてNumber()で変換
- Replyを指定することで戻り値の型安全が保証される

### 設計判断（面接で話せること）
- anyを避けunknownを使うことで型安全性を保つ
- Genericsを使ったAPIレスポンスの共通型定義でコードの重複を避ける
- FastifyのジェネリクスでリクエストとレスポンスをTypeScriptで型安全に扱える


## Issue #20: TypeScript実践 - 非同期・エラーハンドリング・Utility Types

### 学習内容

#### 非同期処理（async/await, Promise）
- async関数の戻り値は必ずPromise<T>になる
- awaitはPromiseを返す関数にかける（外部I/Oが発生する処理）
- awaitなしだとPromiseオブジェクトがそのまま返る（中身が取り出せない）
- 同期関数はPromise不要、非同期が必要なのは外部I/Oが発生する処理のみ

#### エラーハンドリング
- catch(e)のeはunknown型
- プリミティブの型ガード: typeof、クラスの型ガード: instanceof
- instanceof Errorで型を絞り込んでからe.messageにアクセスする
- throwはif の外に出すことで「どんなエラーでも必ずthrowする」を保証する
- Result<T>型でエラーをUnion型として返す設計（RustのResult型に近い思想）

#### Utility Types
- Partial<T>: 全プロパティを省略可能にする（PATCHリクエストで活用）
- Readonly<T>: 全プロパティを読み取り専用にする
- Pick<T, K>: 指定したプロパティだけ抽出する（「これだけ欲しい」）
- Omit<T, K>: 指定したプロパティだけ除外する（「これだけいらない」）
- Partialは型レベルの話、空上書き防止は実装側でundefinedを除外する必要がある

### 設計判断（面接で話せること）
- catchのeがunknown型なのはTypeScriptが型安全を強制するため
- Result<T>型でエラーをthrowせず返す設計はコード予測性が上がる
- PATCHエンドポイントにPartial<T>を使うことで部分更新を型安全に表現できる

## Issue #21: React + TypeScript基礎

### 学習内容

#### 環境構築
- Vite + React + TypeScriptでプロジェクト作成
- Dockerコンテナ上で開発（ports: 5173:5173）
- `npm run dev -- --host` で外部からアクセス可能にする

#### Reactの基本概念
- コンポーネント = 見た目 + 振る舞いをまとめた部品
- 大文字始まり = 独自コンポーネント、小文字 = HTMLタグ
- main.tsx: Reactの起動・マウントのみ
- App.tsx: ルートコンポーネント、ルーティングの起点
- export defaultがないと他ファイルから使えない

#### Propsの型定義
- typeでPropsの型を定義して引数で分割代入
- Optional Props（?）で省略可能なPropsを定義
- 条件付きレンダリング: `{description && <p>{description}</p>}`

#### useStateの型付け
- `useState<number>(0)` で型と初期値を指定
- setXxxを呼ぶと画面が自動で再描画される
- letで管理してもuseStateでないと画面は更新されない

#### イベントハンドラの型付け
- `React.ChangeEvent<HTMLInputElement>` でinputのイベント型を指定
- ジェネリクスで要素の種類を指定することでe.target.valueが型安全になる

### 設計判断（面接で話せること）
- 汎用UI部品（Button, Card）とロジック部品（Form）を分離する
- 同じコンポーネントをPropsで使い回すことで重複を避ける
- shadcn/uiなどのUIライブラリを使う前に手作りで仕組みを理解する
