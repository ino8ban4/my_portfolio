# review: 総括(振り返りテスト)

## 目的
学習全体の定着を確かめる。各Issueの理解度テスト(チャット内)とは別に、ここへ集約する。

## 運用
- topics.md: 振り返りの対象と、弱点メモ。学習が進むたびに足す
- results.md: テストの結果ログ。日付、点数、間違えた点を残す
- exams/: 年末の一斉テストなど
- 月初に、前月の弱点だけを再テストする(間隔を空けた想起)
- 年末(2026-12)に、全範囲の一斉テストを行う
- 演習(コードを書く問題)は platform-engineering/projects/exercises/ に置き、結果は results.md に記録する
